Create complete stage assemblies or work with independent roof and truss-grid layouts. Configure modular components, supports, rails and optional catwalks for concept and event-production planning.

In development / SketchUp

The tool

One workspace for stage and truss assemblies.

  • Three build modes: Complete Stage, Roof Rig Only and Truss Grid Only
  • Modular 4 × 8 ft deck arrays with adjustable support height and placement
  • Optional front-centre catwalk and three selectable perimeter rail styles
  • Truss roof frames, corner blocks, towers and outrigger options using supplied components
  • Perimeter truss grids with configurable dimensions and mounting choices
  • Editable component instances, stored build settings and a copyable material and quantities list
