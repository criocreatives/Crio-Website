In development / SketchUp

The tool

Patterned surfaces, built as geometry.

  • 17 patterns, including herringbone, basket weave, hexagons, diamonds, hopscotch and clapboard
  • Grouped solid geometry with adjustable tile dimensions, thickness, grout and top bevels
  • Layouts clipped to irregular face boundaries and openings
  • Shared pattern grids across adjoining coplanar faces in the same editing context
  • Source material and texture positioning, with seeded per-tile UV and finish variation
  • 2D layout preview, editable settings and updates to previously generated layouts
